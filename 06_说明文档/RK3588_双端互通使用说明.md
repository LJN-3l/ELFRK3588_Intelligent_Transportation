## 这次改的是什么

这次改的是你贴出来的 `RK3588 Flask 仪表盘` 这一条线，不是另外起一套新架构。

保留了你原来的这些入口：

- `/`
- `/chat`
- `/api/stats`
- `/video_status`
- `/video_proxy`
- `/generate_report`
- `/chat_ask`

在这之上新增了：

- `/api/upload_violation`
- `/api/events`
- `/api/events/<id>/review`
- `/api/report`
- `/api/overview`
- `/images/<filename>`
- `/live_overlay_feed`
- `/api/live_status`

## 你现在怎么接

### 1. RK3588 端

把 `rk3588_dashboard_dual_end.py` 放到 RK3588，比如：

```bash
/root/rk3588_dashboard_dual_end.py
```

如果你的模型、ROI、流地址和示例里不同，就改这些环境变量：

- `LIVE_STREAM_URL`
- `LIVE_STATUS_URL`
- `LIVE_BASE_MODEL`
- `LIVE_HELMET_MODEL`
- `LIVE_ROI_JSON`

然后执行：

```bash
sh /root/start_rk3588_dashboard_dual_end.sh
```

或者直接：

```bash
python3 /root/rk3588_dashboard_dual_end.py
```

### 2. 桌面端客户端

你现在的桌面端原型已经有上传能力了，GUI 里把“网页接口地址”填成：

```text
http://你的RK3588_IP:5000
```

例如：

```text
http://192.168.137.82:5000
```

这样桌面端每次抓到违规图，就会自动上传到：

```text
/api/upload_violation
```

## 页面上能做什么

- 看 K230 原始直播：`/video_proxy`
- 看 RK3588 在线 AI 叠加画面：`/live_overlay_feed`
- 收桌面端上传的违规截图
- 人工确认 / 驳回 / 标记重复
- 生成文字报告

## 注意

如果 RK3588 还没装好这些依赖：

- `opencv-python`
- `numpy`
- `ultralytics`

网页侧 AI 叠加流不会启用，但：

- 原始直播依旧可看
- 桌面端上传依旧可用
- 人工审核和报告依旧可用

也就是说，双端互通不会因为网页侧 AI 没装好而完全中断。
